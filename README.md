# 试玩广告引擎识别插件 (v0.3.3)

一个用于一键识别试玩广告（Playable Ads）所使用 H5 游戏引擎的 Chrome 扩展。

## 🎯 插件用途
本插件专为分析可玩广告（Playable Ad）构建，核心功能仅包含：
- **广告平台识别**：判断原始试玩包的目标分发渠道。
- **制作引擎识别**：分析游戏引擎及底层实现框架。
- **渲染库识别**：如果只使用了底层渲染库而未包含游戏引擎，也会予以识别。
- **最终审核结论**：基于分析结果，智能生成业务是否可制作或需人工介入的建议。

⚠️ **注意**：本插件只用于代码检测与特征提取，**不做**资源下载、素材打包、以及深度的反编译重写工作。

## 🚀 安装方式 (Chrome)
1. 打开 Chrome 浏览器，在地址栏输入 `chrome://extensions/`
2. 在页面右上角开启 **开发者模式**
3. 点击左上角 **加载已解压的扩展程序**
4. 选择包含本插件所有文件（含 `manifest.json`）的项目目录即可加载成功。

## 📖 使用流程
1. 在浏览器中打开需要检测的试玩广告页面（可为落地页或单独的纯 HTML 页面）。
2. 点击浏览器右上角的扩展图标，打开本插件。
3. 插件会自动进行检测或可点击“重新扫描当前试玩广告”。
4. 等待几秒钟，查看返回的结果面板中的最终审核结论、置信度以及风险提示。

## 🛡️ 重要规则
- **Luna 引擎绝对优先**：只要识别到 Luna 的强特征证据，将强制定其为主要引擎，忽视干扰关键词。
- **MTG / Mintegral 强确认策略**：对于 MTG 平台，为了防止误杀，仅在满足 “Confirmed”（如明显的水印、明确相关的 URL、或专属运行全局对象）时才认定该素材归属于 MTG，仅存在“弱关键词”时不认定。
- **真 MTG 业务硬性限制**：一旦确认真实包含 MTG 强特征，最终结论将一律锁定为“暂不支持制作”。
- **真 MTG + Luna 冲突排查**：如果确认属于 MTG 平台且引擎被识别为 Luna，输出“规则冲突，交技术复核”。
- **多平台证据统计算法**：对多平台混发情况，只统计经 Confirmed 的平台情况，对弱弱存在的字符字典和数组一律剔除以避免检测污染。
- **识别防身隔离**：插件自带的全部规则表不再进入检测循环，防止检测代码“检测到自己”。

## 🧪 回归测试清单

此列表包含已固化的核心规则测试用例，确保后续规则开发不发生回退。这些用例已完整收录在 `samples.json`。

1. **测试 Luna 非 MTG 弱关键词样本**：验证源码中出现短平台关键词时，只要无强特征就不误杀为 MTG。
2. **测试真 MTG 水印样本**：验证当页面 DOM 渲染明显 MTG 水印时，正确识别并输出“暂不支持制作”。
3. **测试 MTG + Luna 冲突样本**：验证同时命中极强 MTG 和 Luna 时，输出“规则冲突，交技术复核”。
4. **测试 AppLovin + Luna 样本**：验证普通广告平台与 Luna 结合时，正常输出“可进入复刻评估”。
5. **测试 AppLovin + PixiJS 样本**：验证普通平台且 PixiJS 高置信度时，正常输出“可进入复刻评估”。
6. **测试平台关键词污染样本**：验证源码中的多平台支持列表/检测器数组被扫描到时，不会误报多平台冲突，且隔离在忽略或弱证据层级中。
7. **测试 Cocos Creator 版本样本**：验证 2.3.3、2.3.4、2.4.5、2.4.9、2.4.10、2.4.12、2.4.13 均能输出正确版本。
8. **测试 Cocos Creator 版本分流**：验证上述版本输出“可交设计手动处理”，其它已识别版本（如 3.8.3）输出“需程序人工处理”。
9. **测试 Unity Ads 与 Google / AdMob 平台样本**：验证 README 声明的平台能力与规则实现一致。
10. **测试 PixiJS 版本干扰样本**：验证 `Deprecated since v7.2.0` 等废弃提示不会覆盖真实运行版本（如 `PixiJS 7.3.2`）。

可执行规则回归：

```bash
npm run test:rules
```

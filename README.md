# 试玩广告引擎识别插件 (v0.2.4)

一个用于一键识别试玩广告（Playable Ads）所使用 H5 游戏引擎的 Chrome 扩展。

## ⚠️ 重要说明
本插件定位为 **“源码扫描辅助初筛器”**。它通过模拟人工审核流程（在 HTML、内联脚本、外部脚本标识、甚至尝试 fetch 所有外部脚本源码）来搜索关键词。它无法完全取代技术复核，但在大多数情况下能提供极具参考价值的证据。

## 主要功能
- **Phaser/LayaAir/Egret 深度探测 (New)**：增强了这三款引擎的高置信度逻辑、全局变量提取与引擎版本号提取。
- **跨 Frame 结果聚合**：能识别并聚合来自父页面与嵌套 iframe（如 AppLovin 的 raw playable）的结果。
- **多引擎识别**：支持 Luna, Cocos, PixiJS, Phaser, LayaAir, Egret, Three.js 等主流引擎。
- **置信度系统**：基于全局变量、源码关键词、加载日志等维度综合评估。
- **广告平台探测**：识别 MTG, AppLovin, Unity, ironSource, Vungle 等投放平台。
- **样本库回归测试**：支持对比识别结果与人工已确认样本的差异。
- **状态持久化**：扫描过程由后台进程接管，再次打开可恢复上次结果。

## 人工样本库 (Regression Testing)
插件根目录下包含 `samples.json` 文件，用于存放人工确认的样本数据。

### 如何添加人工样本
在 `samples.json` 数组中添加一个对象：
```json
{
  "id": "unique-id",
  "name": "样本描述名称",
  "url": "试玩广告的 URL 或关键路径",
  "expectedPlatform": "预期平台名称",
  "expectedEngine": "预期引擎名称",
  "expectedEngineVersion": "6.5.10",
  "manualEvidence": [ "证据1", "证据2" ],
  "note": "备注说明"
}
```

### 如何进行回归测试
1. 修改 `samples.json` 后重新加载插件。
2. 打开对应的试玩广告页面。
3. 点击“开始识别”。
4. 如果 URL 匹配样本库，顶部会显示“命中回归样本”对比区域：
   - ✅ **一致**：表示插件识别逻辑符合预期。
   - ❌ **不一致**：表示插件逻辑失效，需要点击“复制调试”分析原因。

## 引擎识别规则列表
- **Cocos Creator**: 重点搜索 `cc.game`, `cc.director`, `_CCSettings`, `assets/main/index.js` 等。
- **PixiJS**: 重点搜索 `PIXI`, `PixiJS 6.5.10`, `@pixi`, `pixi.js` 等。
- **Luna**: 重点搜索 `luna runtime`, `luna engine`, `luna playable` 等。
- **Phaser**: 重点搜索 `Phaser.VERSION`, `phaser.min.js` 等。
- **LayaAir / Egret / Construct**: 基于各自的核心运行时特征。

## 安装方法 (Chrome 开发者模式)
1. 在电脑上创建一个名为 `playable-engine-scanner` 的文件夹。
2. 将本项目的所有文件放入该文件夹中。
3. 访问 `chrome://extensions/`，开启 **开发者模式**。
4. 点击 **加载已解压的扩展程序** 并选择该文件夹。
